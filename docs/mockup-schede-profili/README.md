# Mockup di cosmesi: schede del luogo e profili pubblici (20/08/2026)

Bozze grafiche approvate da Alessandro, messe qui perche' la cartella temporanea di lavoro
non e' versionata e si perde.

| File | Cosa e' |
|---|---|
| `schede6.jpg` | le sei schede del luogo, scarrellate per intero |
| `profili.jpg` | i profili pubblici, cinque tipologie piu' la variante influencer uomo |
| `base.html` | foglio di stile comune alle due bozze |
| `costruisci.py` | genera `mock.html` (le schede) |
| `profili.py` | genera `profili.html` (i profili) |
| `mock.html`, `profili.html` | le pagine generate |

Le fotografie usate nelle bozze **non sono qui**: erano immagini di prova scaricate al momento
in una cartella `f/`. Le pagine HTML quindi mostrano i riquadri vuoti finche' non si rimettono
delle immagini in `f/`. Le due immagini JPEG sopra sono la resa completa e sono quelle che valgono.
